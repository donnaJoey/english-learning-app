# 英语打卡 (English Learning App)

这是一个轻量的英语学习打卡和资料管理应用，使用纯前端静态 HTML + JavaScript 实现。它可以帮助你记录每日学习任务、按学习者切换打卡数据，并查看/打印学习资料。

## 功能特点

- 多学习者支持：默认提供“我”和“孩子”两个角色，可在界面中快速切换。
- 每日打卡：为每个学习者设定打卡项，可按“良好 / 优秀 / 卓越”三个等级打分，并累计分数。
- 统计分析：查看近 7 天、近 30 天、累计分数，以及打卡天数与连续打卡天数。
- 学习资料管理：支持固定搭配、听写集、造句/回译、Retell 逻辑骨架、连接词等内容的展示。
- PDF 打印：可选择性打印学习资料，便于离线复习或保存为 PDF。
- GitHub 同步：通过 GitHub PAT 将数据保存到指定的 GitHub 仓库，支持读取、保存和冲突提示。

## 运行方式

1. 打开 `index.html` 文件。
2. 第一次运行时，输入你的昵称（例如“妈妈”或“孩子”）以及 GitHub Personal Access Token。
3. 程序会读取名为 `english-learning-data` 的仓库中的 `progress.json` 文件。
4. 如果文件不存在，会自动初始化一份空文档。

## 数据结构

应用的数据主要保存到以下对象中：

- `learners`：学习者列表
- `template`：每个学习者的打卡模板
- `days`：每天的打卡记录和备注
- `resources`：学习资料（unit / collocations / dictation / sentences / retell / linkers）

## 使用说明

### 1. 打卡

- 在“打卡”页面选择学习者。
- 点击“编辑清单”设置每日打卡项和每项分值。
- 选择对应项的等级（良好/优秀/卓越），分值会自动计算。
- 可在备注框中写下当天想法、感受或新需求。

### 2. 资料

- 在“资料”页面可切换不同学习单元（Unit）。
- 内容包括：
  - 固定搭配清单
  - 听写集（看中文写英文 / 看英文写中文）
  - 造句 / 回译
  - Retell 逻辑骨架
  - 连接词
- 可勾选要打印的部分，然后点击“打印 / 存 PDF”。

### 3. 统计

- 查看近 7 天、近 30 天、累计分数。
- 查看打卡天数和连续打卡天数。
- 点击历史记录可快速跳回某一天的打卡页面。

## 配置说明

应用中有几个关键常量：

```js
const OWNER='donnaJoey', DATA_REPO='english-learning-data', FILE='progress.json';
```

如果你想自定义数据仓库，可直接修改 `index.html` 中对应的值。

## 注意事项

- GitHub PAT 仅保存在浏览器本地 `localStorage` 中，不会写入到仓库里。
- 如果数据被其他人同时修改，页面会提示“有人刚改过，点‘拉取最新’再改”。
- 需要确保 `english-learning-data` 仓库存在，并且 PAT 拥有该仓库的读取/写入权限。

## 适用场景

- 家长陪伴孩子英语学习
- 课程打卡与复习记录
- 学习资料的轻量管理和打印输出
